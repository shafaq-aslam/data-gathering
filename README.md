## 🧩 Mission Statement

This repository is my **Data Gathering Lab**, where I practice how to collect data from different sources:

- 📁 Local file formats (CSV, Excel, TXT)
- 🌐 Web formats (HTML, JSON)
- 🗄️ Databases (SQL)
- 🔗 APIs
- 📤 Exporting data into multiple formats  

Mastering data gathering is essential in data science — it’s the **foundation of every analysis, visualization, and ML pipeline**.
